# PLAN — 기획 요약 · 기능 명세

> 창업아이디어 공모전 출품작. 수치·시장 근거는 사업계획서 기준이며 출처 확인 중인 항목은 ⚠️로 표시.

## 1. 문제

- 고령화로 요양병원·중환자실(ICU)·재택 와상 환자가 늘고 있다.
- 욕창은 치료보다 **예방**이 핵심이며, 기본 수칙은 **2시간마다 체위변경**이다.
- 간호 인력이 부족해 체위변경 **누락**과 **기록 오류**가 자주 생긴다.

## 2. 기존 해결책과 빈자리

| 방식 | 예시 | 한계 |
|------|------|------|
| 웨어러블 센서 | Preveni DecSense (흉부 부착 IoT) | 소모품 비용, 소독, 피부 접촉 부담 |
| 스마트 베드 | 압력 센서 매트리스·모션베드 | 침대당 수백만 원 ⚠️ |
| **PressCare** | 웹캠 + AI 비전 | **추가 하드웨어 거의 없이** 비접촉 추적 + 3D 시각화 |

## 3. 목표 사용자

- **1차**: 요양병원·요양원 병동 간호사/요양보호사 (여러 병상을 한 화면에서 관리)
- **2차**: 재택 와상 환자 보호자 (스마트폰 알림)
- **구매자**: 요양병원 운영자 (기록 업무 감소, 환자 안전 지표)

## 4. 핵심 기능

### F1. AI 자세 분류
- 입력: 병상 위 웹캠(RGB) 영상, 초당 5프레임 내외
- 처리: 포즈 추정(MediaPipe Pose) → 관절 좌표 → 규칙/경량 분류기
- 출력: `supine`(앙와위) · `left_lateral`(좌측위) · `right_lateral`(우측위) · `sitting`(앉음) · `absent`(부재) + `unknown`(판단 불가)
- 같은 자세가 `POSTURE_STABLE_SEC`(기본 30초) 이상 이어져야 자세 변경으로 확정 (깜빡임 방지)

### F2. 체위 타이머 · 자동 기록
- 자세가 확정될 때마다 이벤트 기록 → 현재 자세 유지 시간 계산
- 병상별 하루 체위변경 이력(타임라인) 자동 생성 → 간호 기록 대체/보조
- 간호사가 직접 "체위변경 완료" 확인 버튼을 눌러 기록을 보정할 수 있다

### F3. 실시간 알림
- `REPOSITION_WARNING_MIN`(기본 100분): 노란 경고
- `REPOSITION_INTERVAL_MIN`(기본 120분): 빨간 알림 + 스마트폰 웹 푸시
- 알림 확인(acknowledge) 기록 남김

### F4. 3D 압박 부위 시각화
- 3D 인체 모델 위에 자세별 압박 부위(아래 표)를 누적 시간에 비례해 붉게 표시
- 웹 브라우저에서 회전·확대 (Three.js)

| 자세 | 주로 눌리는 부위 |
|------|----------------|
| 앙와위 | 후두부, 견갑골, 천골·미골(엉치), 발뒤꿈치 |
| 좌/우측위 | 귀, 어깨, 대전자(골반 옆), 무릎 바깥, 복사뼈 |
| 앉음 | 좌골(엉덩이 아래), 천골, 발바닥 |

> ⚠️ 히트맵은 **자세별 유지 시간을 시각화**한 것이며 실제 압력 측정값이 아니다. 화면에 이 점을 표시한다. (D-003)

### F5. 이불·야간 대응 (후순위)
- 이불을 덮어 관절이 일부 가려져도 보이는 관절(머리·어깨)과 윤곽으로 추정
- 어두운 환경: IR(적외선) 카메라 입력 지원
- 인식 신뢰도가 낮으면 `unknown`으로 두고 "확인 필요"로 표시 (틀린 확신 금지)

## 5. 범위 (단계)

| 단계 | 목표 | 포함 기능 |
|------|------|----------|
| **MVP (공모전 시연)** | 병상 1~2개, 웹캠 1대로 시연 | F1, F2, F3(대시보드 알림), F4(기본 히트맵) |
| v1 | 병동 단위 파일럿 | 다병상 대시보드, 웹 푸시, 간호 기록 내보내기(CSV/PDF) |
| v2 | 현장 확장 | F5 이불·야간 대응, IR 카메라, 기존 CCTV 연동, EMR 연동 검토 |

## 6. 차별점

1. **비접촉**: 환자 몸에 아무것도 붙이지 않는다.
2. **저비용**: 웹캠 + 소프트웨어 (스마트 베드 대비 비용 크게 절감)
3. **자동 기록**: 24시간 체위변경 이력을 자동으로 남겨 기록 업무를 줄인다.
4. **3D 시각화**: 어느 부위가 오래 눌렸는지 한눈에 보인다.

## 7. 위험과 대응

| 위험 | 대응 |
|------|------|
| 이불·어둠으로 인식률 저하 | 신뢰도 낮으면 unknown 처리, IR 카메라 옵션, 간호사 수동 보정 |
| 환자 촬영 프라이버시 | 영상은 병상 PC 안에서만 처리, 서버엔 관절 좌표·라벨만 전송, 원본 저장 안 함 (D-002) |
| 의료기기 규제 | "진단"이 아닌 "기록·알림 보조"로 포지셔닝, 규제 해당 여부는 별도 확인 (D-003) |

## 8. 성공 지표 (시연 기준)

- 5가지 자세 분류 정확도 ≥ 90% (이불 없음, 주간 조명, 팀 촬영 데이터 기준)
- 자세 변경 감지 지연 ≤ 60초
- 기준 시간 초과 시 대시보드 알림 지연 ≤ 5초
